# Features


### 1st release (Sept-2025)

Currently under testing ... not all functions mentioned below have been included in the testing (compiled version)

- DICOM viewer (CT/CBCT, MRI)

- Comparison of multiple series - Up to 12 image series displayed in parallel

- Overlays - Contour, images and structure overlays

- 3D/4D visualisation - 3D visualisation with various layers and videos based on 4DCT acquisitions

- Dual-Energy CT - material - Calibration, RED, Zeff and SPR calculation

- Contouring - Drawing tools to create structures

- 4DCT - Evaluation of breathing curves and tools for 4DCT visualisation

- Display brachytherapy treatment plans.

- Brachytherapy dose calculation using TG43

- DVH and clinical metrics

- EQD2

- CT calibration and material maps

- Export contours as STLs (3D printing)

- Ruler, ROI, line profiles

### 2nd release (February 2026)

- Image registration

- Visualisation of EBRT plans (beams, etc)

- Image processing (also batch processing for AI)

- Film calibration
