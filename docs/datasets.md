DECT/PCCT Dataset - https://doi.org/10.5281/zenodo.15119102

This dataset consists of phantom scans that were performed on a photon-counting CT (PCCT) scanner (Siemens NAEOTOM Alpha; Siemens Healthineers, Forchheim, Germany) and on a dual-energy CT (DECT) scanner (siemens SOMATOM Confidence).  AMIGOpy DECT module can be used to process the data.
