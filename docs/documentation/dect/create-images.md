# Create Images


## Material properties maps

1) Go to Eval/Process tab

2) Select the sequences that should be created RED, Zeff, I-value and SPR. Select the Low and High image sequences in the dropdown menus and press "Create Images" (green button)

The images will appear in the list (tree list - left side panel) and can be visualized and processed as any other image. Note that the header of these newly created images still needs to be adjusted (future version) so the images can be exported as DICOM.
