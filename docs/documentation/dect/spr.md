## SPR

 (RED, Zeff, I-value and Zeff vs I-value fits should have been performed)

1) Press Get Ref (Green button below the table) to copy reference values from the main table. Note that materials with the same name (e.g. multiple inserts named solid water) will be plotted on top of each other so rename them (e.g. SW1, SW2, etc)

2) Press Calculate (blue button below the table)

Reference results, calculated values using the fi and deviation will be shown in the table (possible to export as csv) as well in graphs so the user evaluate the results.

Note that the reference energy can be adjusted.
