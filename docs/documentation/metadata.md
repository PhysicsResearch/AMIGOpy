# Metadata


Use the MetaData tab to visualize and navigate the metadata in a user-friendly way. The tree structure allows you to easily explore multiple levels of information. By expanding or collapsing each branch, you can dive deeper into specific sections. The information updates automatically once a series is selected.

# Search

Use the search  box at the bottom-right to type the relevant text (without spaces) to filter the content. The search is case insensitive. Delete the search text to show the complete metadata again.
