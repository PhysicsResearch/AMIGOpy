# Multiple Images


The compare module allows to display of up to 12 images, which is ideal for evaluating 4D-CT images or performing comparisons.

- When selecting the Compare module, click on  "Create" bottom-right and set the number of columns (max. 4) and rows (max. 3)

- Click on a window to make it active and then use the data tree to select an image to display. The active window can be manually selected by adjusting the spin box below the lower-left image.

- Use the dropdown menu to select the image orientation (Axial, Sagittal and Coronal)

- It is possible to sync the slice number, window/level and zoom by using the checkboxes.

Note:

- syncing zoom and slice position won't work properly for different views (e.g. axial and coronal slices shown at the same time) or different image sizes, which is expected.

- AFTER selecting the orientation "Coronal", "Sagittal" or "Axial" select the image  (again) in the list menu to update the view.
