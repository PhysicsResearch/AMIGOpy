# IrIS


IrIS is a custom file used to record data acquired with an imaging panel (not relevant to the majority of the users).

Load IrIS goinf to File >> Open >> IrIS   or Ctrl + I

- AMIGOpy will scan all folders and subfolders and attempt to open all files and will crash if not enough memory is available.

- When selecting the data in the data tree wait for a few seconds until AMIGOpy plots a histogram (see figure below). Currently, it accounts for all the slices to plot the histogram and can take a few seconds for large datasets.
