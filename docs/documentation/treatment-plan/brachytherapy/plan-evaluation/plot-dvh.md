# Plot DVH


To plot the DVH, you first need to calculate the DVHs. Please work through the Documentation on "Calculate DVH" first.

1. Once your DVHs are calculated and shown in the Dose Statistics table, select the DVHs in the Dose Statistics Table you would like to see displayed in a graph.

Click "Select all" if you would like to select all rows at once.

2.Press the “Plot”  button, causing the graph to appear in the Dose Volume Histogram field.

Changing Axes Units

By default, the axes of the graph are:

- Volume in percentage

- Dose in Gray

However, if you would like to change this combination, you can do this by selecting the desired unit for each axis and pressing "Plot".

A new graph will be plotted with the chosen axes units.
