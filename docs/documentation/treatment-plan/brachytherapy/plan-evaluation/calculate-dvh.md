# Calculate DVH


In order to calculate the DVHs,  you first need to create the mask of the desired CT with the desired structures. Please refer to "Create mask" for more information.

If you would like to calculate the dose using TG-43, please first refer to "Calculate Dose with TG-43", then "Create mask" before following the steps below.

Please follow the following steps to calculate the DVH. If you would like to also plot the DVHs after they have been calculated, then please read the documentation "Plot DVH" after you have followed the steps below.

1.Select the doses and structures you would like to use for the DVH (multiple selections are allowed for both fields).

![Image](https://sites.google.com/sitesv-images-rt/ACHe0d3p9mNBWHcN7jhnd0ieuxFx-lXkNe0G7b39xCcEeos3uk-7fSGDl_0jYOeLGnVTO9dJx413jctlXvMdo9fwSKNxyg59a7n5Tjqz2JugQKjluWvl75CnFnIwOjSNqMuAh8FdGKR2hihZPSrf4g8miNX0rt0H10-ELoLQqAKmi5kPFRAxd27JFSCODKLGUuEwATymmqJj1TZjkWxdwegMT6h039SHPMDLs5jfoDQc5eM=w1280)

2.Enter the reference dose. If left blank, the system will use the maximum dose as the reference dose (shown in pop-up screen).

3. Press "Calculate DVHs".

![Image](https://sites.google.com/sitesv-images-rt/ACHe0d3urUQY0WbtWsLsQ4LyRSvZ-96JLgj3BNn1zrvAkGVq3wi8vRv9-pZDWs8ySmltwTOE_n38g1ZHCsOWsYSSWTBWf4m8dffE7RKpIlpXEddc381iwmK5SoHUbrRbWABahlRNpVcUJ3Hzwjd_Qzwo6tSdHxTHlZsCtMojhGQ25_VSltN8CReb1Y7nBV6f0hMlKGrstloRK9wI_srKK-FBZun7HyJwVRCRkxZUxN98=w1280)

4. Now the DVHs for each structure en dose combination will appear in the Dose Statistics Table.

(basis statistics are showed: volume, reference dose, maximum dose, minimum dose, and mean dose)
