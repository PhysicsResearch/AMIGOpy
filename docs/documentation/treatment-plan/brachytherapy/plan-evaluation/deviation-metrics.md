# Deviation Metrics


Common deviation metrics are the metric for Volume (Vxx) and the metric for Dose (Dxx).  Follow the steps to calculate and add these metrics to the Dose Statistics Table.

It is also possible to only calculate one of the two metrics.

1.Enter the threshold value you would like to calculate for Vxx (& Dxx) metric.

2.Choose the input & output unit for the calculation of the Vxx (& Dxx) metric by clicking one of the two options in the drop-down menus.

![Image](https://sites.google.com/sitesv-images-rt/ACHe0d1ccoJBwQIpndccyJH6i_kYY7-b2B_0hQ75E0l8tCf4w3lvjkL-PJEsMasOno6QxjTr8iCPnsr8t9wUZoLG2rS9v9zFoMzXhYeC7kzid0xlkAGKYXZFbm9133NGBz8tYAUhQ3dDaqgjDd9pTv4D2xov3KnS1k6AXn49Tgyyjn46AJI8eGEX6oGLyLyQnpBG8V1LnhhOI73QaFu4X3SvVCUKJyHbn__FzNluhm8CVvQ=w1280)

Multiple Vxx or Dxx calculations

If you would like to add calculations for different values for the Volume or Dose metric, you can do this by repeating the steps mentioned above.

Deleting Column for Dose Statistics Table

To delete a column for the Dose Statistics Table please proceed as follows:

! Standard Dose Statistics columns (DVH ID, Structure, Dose, Volumn, Reference Dose, Max Dose, Min Dose, Mean Dose) cannot be deleted from the Dose Statistics Table.

1.If you calculated a Vxx or Dxx that you no longer what to display in the Dose Statistics Table, you select one cell in the column you would like to delete.

2.Press the "Delete column" button.

For example, you would like to delete the V10(Gy) column:

The cell with the value 10.25 is selected. When pressing “delete column” in the top right corner, the column is deleted from the table.

![Image](https://sites.google.com/sitesv-images-rt/ACHe0d1dwWK7nz9LuaveCyYNA63ct0raGgzgt8HpwgWi29_hNRO0kBvC1bTsqLfdIWqbDTuzNFmj5vaBMOFM3Uisg3OdDmMd8nWERFjU9P60tNpRBUHXWRGrPDOlMMntjlZiO6uMeY9rLjQcRPKlU6_3_476ZjNcUHmDjr_Q4M-RXg2V9guyRS8UIT7makiUfMlLQa5_V2BnABAa9SMnnaMrERItZrQ51UJiN_lU04yxQ9A=w1280)
