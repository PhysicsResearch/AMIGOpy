# Uncertainty Bands


To generate the uncertainty bands, you first need to calculate the DVHs. Please work through the Documentation on "Calculate DVH" first.

Step to generate the uncertainty bands:

- Fill out the uncertainty values of the source tracking device used during treatment.

- Fill out the number of iterations you would like to use for generating the uncertainty bands.

- Press the button "Show Bands".
