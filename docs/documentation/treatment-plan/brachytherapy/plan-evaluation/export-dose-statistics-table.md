# Export Dose Statistics Table


When exporting, the system will export all columns and rows shown in the Dose Statistics Table. Therefore, you do not need to select the rows you would like to export.

If you have calculated deviation metrics that are included in your Dose Statistics Table but do not want them in your export, follow the steps in the "Deviation Metrics" documentation to delete the relevant columns from the table before exporting.

Steps to Export Dose Statistics Table to CSV:

1. Click "Export to CSV".
