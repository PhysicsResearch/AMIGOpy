# Navegation and Zoom


Zoom

Right Button Down and Hold: Pressing and holding the right mouse button, then moving the mouse, triggers a zoom action. Moving the mouse up zooms in, and moving it down zooms out. This allows users to inspect specific areas of the image or model more closely.

Slice navegation

Mouse Wheel: Rotating the mouse wheel changes the slices of the image the cursor is hovering over.

Slide bar: Drag the slide bar under each window to change the slice being displayed
