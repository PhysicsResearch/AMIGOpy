# View >> Window  menu

Values can be set to pre-defined settings using View >> Window or shortcuts e.g. Ctrl+1 or Ctlr+2

Custom numerical values can be set manually by selecting Custom or using Ctrl+0

The histogram at the bottom-right shows the distribution of the voxel values over the full 3D matrix. Use the interactive tools on top of the histogram to adjust it.

# View >> Color menu

Colormaps can be set to pre-defined settings using View >> Color

Note that the color map will be applied to the current layer. Therefore, different colormaps can be used.
