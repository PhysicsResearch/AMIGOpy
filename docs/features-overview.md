# Features  Overview

AMIGOpy is currently under development. Many of the features available in the Matlab version are not yet implemented, and the ones that are available still need to be tested. Be aware that it may be unstable and has not been tested with large datasets. Nevertheless, some features are already useful. Please report any issues.

Available features:

- Layer overlays - Up to 4 layers

- DICOM images

- open, display, show multiple panels for comparison, and overlay images.

- select cylindrical ROIs

- DECT

- Perform DECT calibration

- Create RED, Zeff, I-values, and SPR using multiple methods

- 4DCT

- Display 4DCT series as videos, multiple series comparison

- Metadata

- Display DICOM metada

- RTDoses

- Import and display RTDoses

- RTPlan Brachy

- Show dwell times, positions and channel positions (graphs and tables)

- Overlay channels and display them combined with images and dose distributions.
